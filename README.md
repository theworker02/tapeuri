# tapeuri

Tape HTML/Markdown uri fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/tapeuri/

## Install / run

```bash
git clone https://github.com/theworker02/tapeuri.git
cd tapeuri
node src/cli.js
node --test
```
